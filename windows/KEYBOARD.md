# Swap Esc and CAPS-LOCK key

- Install Windows PowerToys and use the Keyboard-Manager to swap (caps-lock => esc and esc => caps-lock) the keys.

# Install no dead key layout

- [https://github.com/RAnders00/Deutsch-ohne-Tottasten](https://github.com/RAnders00/Deutsch-ohne-Tottasten) no nead keys german keyboard layout.
- To install:
  1. install Microsoft keyboard layout creator
  2. load the german.klc file in the keyboard layout creator
  3. use Project->Build to build the keyboard layout
  4. mklc will prompt for logs => NO, and to open the created layout in explorer => YES
  5. double click setup/install.exe
  6. restart pc
  7. go to Einstellungen->Zeit und Sprache->Sprache und Region->Deutsch (3 Punkte)->Sprachoptionen->Tastatur hinzufügen->Deutsch - ohne Tottasten
  8. delete the old keyboard layout ("Deutsch")
